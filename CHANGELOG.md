# Changes

Each release gets a section here, written for the people who use the program. The release workflow copies
the section into the GitHub release notes, and refuses to publish a version that has no section.

## Unreleased

- Photo Recovery now opens in a window of its own, like any other Windows program, instead of a black
  command window and a web browser. It has a new look to match Windows 11, and follows light or dark mode.
- A proper installer: Start menu entry, desktop icon, and uninstall from Settings > Apps. No administrator
  needed to install. A portable zip is still available.
- You now choose where rescued photos go: your Pictures folder, your Desktop, or a folder of your choice.
- When it's finished, the program offers to delete the copy of the card to free up space, and explains why
  the card itself is best left alone for now.
- A plain-English README.
